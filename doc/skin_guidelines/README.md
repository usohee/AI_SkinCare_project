대한피부과학회와 대한피부과의사회는 다른 기관이다. 학회의 2015년 글은 교육자료이며 최신 임상 지침이 아니다.
건조·단순지성·복합지성 관리 부분만 사용한다. 시술·약물·질환 원인 추정은 리포트에서 제외한다.
`self_reported_skin_type`이 없으면 유형별 자료를 선택하지 않는다. 피지 점수·밝기로 유형을 판정하지 않는다.
`combination_oily`는 원문의 복합지성에 대응하며 일반 복합성 전체에 확대 적용하지 않는다.
HTML 원문 전체를 모델에 보내지 않고, KB의 검토한 요약·적용 범위만 보낸다.
시간·빈도 등은 확인한 공식 문구만 사용한다. 저작권 연도를 발행일로 사용하지 않는다.
`manifest.json`에는 파일별 원문 URL, 확인일, SHA-256과 본문 키워드 검사 결과가 기록된다.
