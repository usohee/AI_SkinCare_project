# 앱 ↔ 서버 연동 가이드 (Android)

서버 실행: `cd backend` → `python main.py`  (기본 포트 5000. 8000으로 쓰려면 `$env:PORT=8000` 후 실행)
서버 주소: 에뮬레이터 `http://10.0.2.2:5000/` / 실기기는 같은 와이파이의 PC IP
상태 확인: `GET /health`    시연 계정: `demo@mirrorme.com` / `demo1234`

> **서버는 `backend/main.py` 하나만 사용한다.** `backend/test.py`는 이 서버로 대체되어 삭제되었다.
> 앱에 필요한 변경(리포트 글, 추천 제품, 기록 형식)은 `app/` 안에 이미 반영되어 있으니 `test.py`를 다시 만들지 말고 필요한 기능은 서버 담당(예진)에게 요청한다.

## 앱 모델 ↔ 서버 응답

| 앱 (`SkinAnalysisResponse`) | 서버 필드 | 비고 |
|---|---|---|
| `totalScore` | `total_score` | 높을수록 양호 |
| `scores` (acne, pigmentation, pore, sebum) | `scores` | **감점** (낮을수록 양호) |
| `date` | `date` | `YYYY-MM-DD` (한국 시간) |
| `llmReport: String?` | `llm_report` | 앱 화면에 바로 보여 줄 수 있는 글 (문단·글머리 포함) |
| `recommendations` (name, brand, imageUrl) | `recommendations` (name, brand, `image_url`, + category, reason) | |

- `/history/{user_id}` → `{success, user_id, history: [위와 같은 모양]}`, **최신순**.
- 로그인 `POST /login` → `{success, user_id, nickname}` / 실패는 HTTP 401 (`message` 포함).
- 회원가입 `POST /signup` → 201 `{success, user_id}` / 중복은 409.

## 제품 이미지 (앱에서 해야 할 일)
서버는 `recommendations[].image_url`로 **직접 만든 제품 이미지**(PNG, 320×320)를 준다. 외부 쇼핑몰 주소가 아니라서 인터넷 없이도 뜬다.
그런데 앱의 `ProductItem`(ReportScreen.kt)은 이미지를 그리지 않고 회색 상자에 "이미지" 글자만 표시한다. 이미지를 보이려면 앱에서 URL 이미지를 불러와야 한다.

1. `build.gradle.kts` (app)에 Coil 추가
   ```kotlin
   implementation("io.coil-kt:coil-compose:2.7.0")
   ```
2. `ProductItem`에 `imageUrl` 인자를 추가하고, 회색 상자 안의 `Text("이미지")` 자리에 이미지를 그린다.
   ```kotlin
   import coil.compose.AsyncImage
   import androidx.compose.ui.layout.ContentScale

   @Composable
   fun ProductItem(brand: String, name: String, imageUrl: String? = null) {
       Row(modifier = Modifier.fillMaxWidth(), verticalAlignment = Alignment.CenterVertically) {
           Box(
               modifier = Modifier.size(80.dp).clip(RoundedCornerShape(12.dp)).background(Color(0xFFF5F5F5)),
               contentAlignment = Alignment.Center
           ) {
               if (imageUrl.isNullOrBlank()) {
                   Text("이미지", fontSize = 12.sp, color = Color.LightGray, fontFamily = MM_Font)
               } else {
                   AsyncImage(model = imageUrl, contentDescription = name,
                              modifier = Modifier.fillMaxSize(), contentScale = ContentScale.Crop)
               }
           }
           // 이하 기존 코드 그대로
   ```
3. `ProductSection`에서 호출할 때 `imageUrl = recommendation.imageUrl`를 넘긴다.

## 자주 나는 문제
| 증상 | 원인 |
|---|---|
| 네트워크 오류 | 서버가 꺼져 있음 / 주소·포트가 다름 / `usesCleartextTraffic` 없음 / 대기 시간(기본 10초) 부족 → `RetrofitClient`에서 60초로 |
| 분석 실패: 400 | 사진이 비었거나 이미지가 아님 |
| 리포트가 규칙 기반 | 서버 `.env`에 LLM 키가 없거나 호출 실패 → 응답의 `llm_metadata.fallback_reason` 확인 |
| 제품 이미지가 회색 상자 | 위 "제품 이미지" 1~3 적용 필요 |
